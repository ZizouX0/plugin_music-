1 · The two cue types — when to use each

🔺 Memory Cue = your MAP

Use to navigate the track and know when to mix.

  • Mark every section start (intro, build, drop, breakdown, outro)
  • On CDJ: jump between them with the search arrows
  • Unlimited — be generous
  • One is the load point (where the track cues on load)

For finding your place & timing transitions.

🎛️ Hot Cue = your HANDS

Use to perform — instant one-tap jumps.

  • Loaded on the A–H pads (8 on FLX4 = 8 on CDJ-3000)
  • Smash to the drop, fire a vocal, reload, loop-in
  • Max 8 — reserve for things you trigger live
  • Shown as coloured markers on the waveform

For live triggers you hit with your fingers.

The pro move: set the drop, mix-in, mix-out & breakdown as BOTH. Right-click a Hot Cue → Save as Memory Cue. Now they work on every player and one tap / one arrow away.

4 · Per-track prep order (do the same every time)

  1. Analyze → check the beatgrid downbeat sits on beat 1
  2. Quantize ON
  3. Set A / C / G (mix-in, drop, mix-out) as Hot + Memory — the non-negotiables
  4. Add B, D, E, F, H if the track needs them
  5. Colour the Hot Cues per the map
  6. Fill the Comment, add My Tags, set a Rating
  7. Drag into the right Playlist
  8. Playlists done → export to the gig USB (re-export after ANY change)

Prep your next 20–30 tracks first — not the whole library at once.

5 · Harmonic mixing quick-ref (for clean mixes & mashups)

What keys blend

Same key8A → 8A · perfect
±1 on wheel8A → 7A or 9A · smooth
Relative maj/min8A ↔ 8B · mood shift
+7 (energy boost)8A → 3A · lifts the room

Acapella must match the instrumental's key (or key-shift it).

Tempo (BPM)

  • Within ±6% pitches cleanly
  • Bigger gap → use half / double time (e.g. 140 over ~70)
  • Sort a playlist by Key or BPM — compatible neighbours jump out

Mashup = compatible key and tempo, then mark the in/out cues on both tracks.
