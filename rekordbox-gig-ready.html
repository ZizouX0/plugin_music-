🎯 The whole idea in one line

Your computer's Rekordbox collection is the master. The FLX4 plays straight from it; a CDJ plays from a USB you export from it. Same cues, colours & tags travel to both — so you only ever prep once.

1 · Prep in Rekordbox
Analyze, cue, tag every track the same way. The FLX4 reads this live.
2 · Keep ONE gig USB
Export your playlists to it. Re-sync before every gig = instant CDJ-ready.
3 · Same layout everywhere
8 pads on the FLX4 = 8 Hot Cues on a CDJ-3000. Muscle memory carries over.

Per-Track Prep Routine (do the same every time)

  1. Analyze the track (set analysis to Normal/Dynamic for electronic; check the beatgrid downbeat lands on beat 1).
  2. Turn Quantize ON — every cue snaps to the grid, so nothing is ever off-beat.
  3. Set your cues on phrase starts (every 8/16/32 bars, on the downbeat) — see the cue map →
  4. Set key points as BOTH Hot Cue + Memory Cue (right-click Hot Cue → Save as Memory). Works on any player, old or new.
  5. Colour-code the Hot Cues by function (see map). Same colours on every track.
  6. Fill the Comment with mix info / mashup partner (shows on CDJ browse).
  7. Tag it with My Tag (genre, energy, vocal, mashup-ready) for instant filtering.

Because the FLX4 reads all of this from your collection, doing it once automatically makes the track CDJ-ready the moment you export.

Memory Cues = your map (navigate + know when to mix). Hot Cues = your hands (instant pad triggers). The 4 marked ✅ are the ones every track must have as both.

The 2 cues that matter most

  • Mix-IN (Pad A / green) — first clean downbeat where the next track can enter.
  • Mix-OUT (Pad G / white) — where you start blending the current track out.

Nail these two on every track and 90% of tight mixing is done — on the CDJ you flick between them with the search arrows.

Everything else is a bonus. If you only cue two points, cue these.

Mashup Prep & Tagging (hints that survive to the CDJ)

First check they fit

Key: same Camelot, ±1 (7A↔8A), or relative major/minor (8A↔8B). Acapella must match the instrumental's key.   BPM: within ~±6%, or use half/double time.

Then leave breadcrumbs (all export to USB)

Comment fieldpartner + instruction, e.g. “MASH → Titanium acap @ drop | 8A | in on HC-H” — shows on CDJ browse
My Taga “Mashup” category: Layer-ready, Acap, Mash-pair → filter instantly
Same colourgive both tracks of a pair the same track colour
Named Hot Cuename the launch point “MASH IN – Levels acap” (name shows on CDJ-3000)
Playlistfolder MASHUPS → one playlist per combo, base track then layer, side by side

Tip: sort a playlist by Key or BPM and compatible neighbours jump out — a fast way to find new pairs.

Playlist Structure

  • 📁 SETS — one playlist per gig/vibe, in play order
  • 📁 MASHUPS — one playlist per combo
  • 📁 CRATES — by genre / energy
  • ⭐ NEW / TO-PREP — un-cued tracks land here first

Use Intelligent Playlists (auto by BPM/key/rating) so crates fill themselves.

Export & Backup Drill — the one habit that keeps you CDJ-ready

Before every gig

  • Format the gig USB exFAT (or FAT32) — most reliable on CDJs.
  • Rekordbox → Export mode → drag your SET + MASHUPS playlists onto the device.
  • Or use Sync Manager to update only what changed.
  • Safely eject. Carry a 2nd identical USB as backup.

Golden rules

  • Re-export after ANY cue/track change — the USB is a snapshot, not live.
  • Never drag-copy USB→USB in Finder/Explorer — it breaks cues. Always export from Rekordbox.
  • Keep the collection backed up (Rekordbox → Backup Library) so cues are never lost.

At the club (CDJ)

  • Plug in → browse by Playlist → your cues, colours & comments are all there.
  • Memory Cues = search-arrow navigation; Hot Cues = pads A–H.
  • Set new cues on the CDJ? Save to USB, then Import to Collection back home so nothing is stranded.
